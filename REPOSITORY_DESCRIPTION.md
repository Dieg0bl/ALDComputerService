# Propuesta de Descripción para el Repositorio ALDComputerService

## Descripción Concisa para la Sección "About"

**Español:**
Sistema de gestión integral para centros de servicio técnico informático desarrollado en Java. Permite administrar inventarios de equipos (Desktop, Laptop, Server), gestionar solicitudes de reparación, generar reportes en PDF y administrar datos de establecimientos. Construido con Java Swing, MariaDB, JasperReports y arquitectura MVC.

**English:**
Comprehensive management system for computer service centers developed in Java. Features equipment inventory management (Desktop, Laptop, Server), repair request tracking, PDF report generation, and establishment data administration. Built with Java Swing, MariaDB, JasperReports and MVC architecture.

## Descripción Extendida (Opcional)

**Español:**
ALDComputerService es una aplicación de escritorio desarrollada en Java que facilita la gestión integral de equipos informáticos y sus mantenimientos en centros de servicio técnico. La aplicación implementa un sistema completo de inventario y seguimiento de reparaciones con interfaz gráfica intuitiva y capacidades de generación de reportes profesionales.

**English:**
ALDComputerService is a Java desktop application that facilitates comprehensive management of computer equipment and maintenance in technical service centers. The application implements a complete inventory and repair tracking system with an intuitive graphical interface and professional report generation capabilities.

## Tecnologías Principales
- Java 11
- Java Swing (GUI)
- MariaDB (Database)
- JasperReports (PDF Generation)
- JFreeChart (Charts)
- Ant (Build System)
- MVC Architecture

## Funcionalidades Clave
- Gestión de inventario de equipos
- Seguimiento de solicitudes de reparación
- Generación de reportes en PDF
- Administración de datos de establecimientos
- Sistema de reloj y alarmas
- Conectividad con base de datos
